# The Slate Diner

A modern, desktop-focused restaurant website built as part of The Odin Project curriculum.

The Slate Diner showcases a restaurant website experience with a clean interface, thoughtfully structured pages, and an engaging design.

## Features

- Multi-page website navigation
- Desktop-focused layout
- Dedicated Home, Menu, About, Contact, and Reservation sections
- Dynamic page rendering using JavaScript modules
- Interactive navigation with active-page styling
- Custom styling and visual elements

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Webpack 5
- npm




## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (comes with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/soorekdev/the-slate-diner.git
   ```

2. Navigate into the project directory:

   ```bash
   cd the-slate-diner
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

### Running the Project

Start the development server:

```bash
npm start
```

### Building for Production

```bash
npm run build
```

## Project Status
